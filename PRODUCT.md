# Forking Hell

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

A fully controlled endless pixel platformer. The player is an Octocat on a traversable git network graph. Horizontal movement advances, freezes, or reverses environmental time; jumping stays forward-only.

## Capabilities and Constraints

Branch recursively, contact switches to stage targets, and merge one level at a time to turn staged obstacles into coins. Ranged sources remain active on every branch. Rewards, staging, destruction, and merges are permanent. Each copy can reward once. Distance scores maximum forward progress.

Desktop keyboard and simultaneous mobile touch are required. Phaser 4, TypeScript, one common low-resolution composition shader, integer physical-pixel presentation, and static hosting. No accounts or backend.

Character frames and movement states follow the author's labeled 26x27 atlas contract. Enemy art uses the same native texel scale. Forks are traversable one-unit slopes. The camera has a wider initial view, a central deadzone, directional look-ahead and depth-dependent zoom; its readability floor never caps gameplay depth.

## Brand Commitments

The title is **Forking Hell**. Preserve the supplied authored Octocat poses and silhouette, recolored into the shared indigo/purple/cyan world. References inform negative space and relationships, not scenery to copy.

## Evidence on Hand

The user confirmed authorship and permission to redistribute the Octocat sheet. Code is MIT; the character artwork retains separate terms and GitHub trademark rights. Reference JPG/GIF and private prototype materials must not enter this repository.

## Product Principles

- Time is controlled by actual player movement, never camera motion.
- Permanent progress is not historical undo.
- Branching creates opportunity without removing ranged risk.
- Every world element shares the same pixel lattice.

## Accessibility & Inclusion

Shape distinctions, reduced flashes/shake, independent audio controls, explicit pause and focus handling, touch safe areas. Gameplay remains a visual platformer; do not claim full screen-reader playability.

## Open Decisions

External Game Off eligibility and submission remain pending user review. A public preview or ZIP is not a jam submission.
